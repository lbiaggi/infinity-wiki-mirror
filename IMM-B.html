IMMOBILIZED-B
ACTIVATION
  • The Trooper or game element ("Trooper" from now on) suffers a successful Attack or Effect using an Ammunition, Hacking Program or a game condition or Scenario Special Rule, capable of causing this state.
EFFECTS
  • Troopers in Immobilized-B State cannot declare any Skill, Attack or ARO, except Reset applying a -3 WIP MOD.
  • Automatic Special Skills and Equipment continue to work, but the Trooper must still respect all declaration restrictions.
  • Troopers in the Immobilized-B state continue to provide Orders for their Order Pool.
CANCELLATION
  • The affected Trooper may cancel this state via a successful Normal or Face to Face Reset Roll, applying the -3 WIP MOD provided by this state.
  • A Trooper with the Engineer Special Skill (or an equivalent Skill) may cancel the Immobilized-B state by spending one Short Skill of an Order while in Silhouette contact with the affected Trooper, and passing a Normal WIP Roll (or the Roll specified by the Special Skill or Scenario).


Examples

Update PDF 5.3, September 2026

Hacking Program vs. Trooper in Immobilized-B State

Let’s suppose a Reactive Trooper is in Immobilized-B State. With an Order, the Active Trooper declares Move + Trinity against the Immobilized Trooper.

In this state, the Immobilized Trooper can only declare Reset as their ARO, with a MOD of -3.

Therefore, a Face to Face Roll occurs: three Trinity WIP Rolls against one Reset WIP Roll.

For the Reset Roll, the Trooper in Immobilized-B State applies the following MODs:
-3 for Immobilized-B State.

Let’s suppose the Immobilized Trooper has a WIP Attribute = 13, so the Success Value (SV) is 13 – 3 = 10.

For the Hacking Roll, the Active Trooper applies the following MODs:
+3 for the Attack Modifier provided by Trinity.

If they have a WIP Attribute of 13, the Success Value (SV) is 13 + 3 = 16.

Resolution:

The Active Trooper achieves three successes with their Rolls.

The Immobilized-B Trooper fails their Reset Roll, so they suffer all three hits from the Trinity Hacking Program. Therefore, they must make three Saving Rolls.

However, if the Immobilized-B Trooper wins the Face to Face Roll, they not only avoid all the hits but also cancel their Immobilized-B status.


SEE ALSO

Carbonite

  • Any failed Saving Roll causes the target to enter Immobilized-B State, placing an Immobilized-B State Token (IMM-B) by them.


Electromagnetic (E/M) Ammunition

  • If the target fails a Saving Roll and is Heavy Infantry (HI), a TAG, a Remote (REM), or a Vehicle (VH), then it also enters Immobilized-B State. Place an Immobilized-B Token (IMM-B) next to it in addition to the Isolated Token.


Cybermines

  • However, any Troopers with the Hackable Characteristic (HI, REM, TAG, VH...) and Hackers who fail either Saving Roll enter Immobilized-B State instead of Stunned State.


Guts Roll Requirements

  • The Trooper is not in an Engaged, Null or IMM State.


FAQs

N5 FAQ
Version: 0.1, Sep 2026

Q: In the Active Turn, if a Peripheral's Controller is unable to declare a Skill (due to being Stunned, Immobilized etc.), can the Peripheral still declare the Skill?

A: Yes. The Controller and all their Peripherals declare the same Skill, and any of them that can't declare the Skill instead Idle.
